# 核心準則

1. **有機配色 (Organic Palette)**：
    - **基底 (Base)**：使用溫暖的米色/奶油色 (`#F5F5DC`, `#FAFAF5`) 代替純白背景。
    - **主色 (Primary)**：提取 Logo 中的植物綠 (`#6B8E23`) 與深橄欖綠 (`#4A6741`)。
    - **文字 (Text)**：使用深褐灰色 (`#3E2723`, `#2D3748`) 代替純黑，減少視覺銳利度。

2. **溫潤排版 (Humanist Typography)**：
    - 使用圓潤或人文主義的無襯線字體（如 **Outfit**, **Manrope**, 或 **Plus Jakarta Sans**），呼應 Logo 的現代與親和感。
    - 標題應有足夠的呼吸感 (Letter Spacing)，不追求極致緊湊。

3. **柔和幾何 (Soft Geometry)**：
    - **圓角戰略**：全面使用大圓角 (`rounded-2xl`, `rounded-3xl`)，拒絕銳利邊角。
    - **深度 (Depth)**：使用柔和的瀰散陰影 (`shadow-lg`, `shadow-green-900/5`) 營造卡片懸浮感，而非硬邊框。

4. **自然動效 (Natural Motion)**：
    - 交互動畫應模仿植物生長或呼吸（Ease-out, Slow），避免機械式的線性移動。
    - 按鈕點擊應有柔軟的下沉感 (Scale down)。
