# 核心準則

1. **沉浸式 App Shell**：
    - 保留底部的「播放控制條」作為常駐元素，設計成類似「浮島 (Floating Island)」的樣式，不遮擋內容。
    - 確保頁面切換如流水般順暢 (View Transitions)。
2. **離線體驗 (Zen Offline)**：
    - 當斷網時，不顯示恐龍或錯誤，而是顯示一個「平靜的冥想/休息畫面」，提示用戶專注當下或聆聽已下載內容。
3. **安裝引導 (Nurturing Install)**：
    - 安裝提示語應溫柔：「將成長思維種植在您的主畫面 (Plant this app, grow daily)」。
    - Icon 使用 Logo 的圓角版本 (Maskable Icon)。
4. **音頻控制**：
    - 完整支援鎖屏播放資訊與背景播放，確保學習不中斷。
