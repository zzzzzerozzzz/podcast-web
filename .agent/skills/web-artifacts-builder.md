# 核心準則

1. **技術堆疊**：Next.js 14 (App Router), Tailwind CSS v4, Lucide Icons (使用圓潤風格圖標)。
2. **組件風格 (Component Style)**：
    - **Cards**：類似厚紙卡片或磨砂玻璃，背景色需帶有微透明度 (`bg-white/80` + `backdrop-blur`)。
    - **Buttons**：藥丸形狀 (`rounded-full`)，主按鈕使用漸層綠色。
    - **Inputs**：背景色淡雅，聚焦時顯示柔和的綠色光暈 (`ring-green-400/50`)。
3. **圖標運用 (Iconography)**：
    - 選用與「生長/學習/音頻」相關的 Icon (Sprout, Mic, Play, Sun)。
    - 線條粗細適中 (`stroke-width={2}`)，保持視覺的穩重感。
