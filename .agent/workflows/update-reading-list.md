# 更新書單工作流程

## 使用方法

您只需要用自然語言告訴 AI 助理（我）以下資訊：

### 📌 範例指令

```
請幫我更新這個月的書單：

1. 書名：《窮查理的普通常識》
   作者：查理·蒙格
   我的心得：這本書讓我學會用多元思維模型來解決餐飲管理的複雜問題。

2. 書名：《刻意練習》
   作者：Anders Ericsson
   我的心得：提升員工技能不是靠年資，而是有目標的練習。這改變了我設計培訓的方式。

3. 書名：《精準提問》
   作者：Frank Sesno
   我的心得：好的問題比好的答案更重要。這本書教我如何用提問引導團隊思考。
```

### 📋 AI 會自動執行的步驟

1. **生成書封圖片**：使用 AI 繪製符合網站風格的極簡書封
2. **更新程式碼**：修改 `components/Blog/BlogList.tsx` 中的書單區塊
3. **儲存圖片**：將新書封存放到 `public/books/` 資料夾
4. **驗證效果**：開啟瀏覽器截圖確認顯示正確

### 📂 相關檔案位置

- **書封圖片**：`public/books/` 資料夾
- **書單內容**：`components/Blog/BlogList.tsx` (Line 178-242)

### ⚡ 快速指令

如果您只想換一本書，可以這樣說：

```
把《Zero to One》換成《從 A 到 A+》，作者是 Jim Collins，心得是「優秀是卓越的敵人」
```

或者只更新心得：

```
把《原子習慣》的心得改成：每天進步 1%，一年後你會進步 37 倍。這是我給團隊的口號。
```
