# 內容管理指南 (CMS)

## 如何新增文章

您只需要在 `content/posts/` 資料夾中新增一個 `.md` 檔案即可。
檔案名稱將成為網址的一部分（例如：`my-new-post.md` -> `/blog/my-new-post`）。

### 文章格式範例

請複製以下格式到您的新檔案中：

```markdown
---
title: "您的文章標題"
date: "2026-02-01"
category: "思維心法" # 可選：思維心法, 日常習慣, 數位生活, 生產力, 自我照顧
excerpt: "這是顯示在列表頁的簡短摘要，請控制在 50-80 字以內。"
readTime: "5 分鐘閱讀"
featured: false # 是否在首頁精選顯示 (true/false)
---

# 這是主標題

這裡開始寫您的文章內容...

## 這是副標題

- 支援列表
- 支援 **粗體** 和 *斜體*
- 支援引用：

> 這是一段引用文字。
```

### 注意事項

- `date` 格式必須為 `YYYY-MM-DD` 或 `YYYY年 MM月 DD日`，系統會根據日期自動排序。
- `category` 建議使用現有的分類，但也支援新分類。
- 圖片目前尚未連結到實際儲存空間，若需插入圖片，請使用標準 Markdown 語法 `![Alt](image-url)`。
