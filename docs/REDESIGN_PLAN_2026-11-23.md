## 1. 改版核心方向與視覺定位

### 設計定位：**「暖調生活誌 × 質感 Blogger 動態風」（Warm Lifestyle Creator Editorial）**
保留真實港人美食旅遊 Blogger 的溫度、品味與在地信任感，避免過於冰冷的 4A 企業廣告風，同時導入流暢且有層次的 `framer-motion` 互動與動態節奏，在進站前 3 秒吸住商家目光並引導順暢往下瀏覽。

### 色彩系統（Color System）
| 用途 | 色碼 | 視覺角色 |
| :--- | :--- | :--- |
| **主背景（奶油米白）** | `#FAF7F2` | 溫潤雜誌紙感，讓夕陽大片、實景照、Meta 數據與 QR Code 自然融合 |
| **次背景／卡片底** | `#FFFFFF` / `#F2ECE1` | 乾淨清爽的層次對比與細緻邊框（`#E6DEC8`） |
| **品牌主色（深橄欖綠）** | `#2C3E26` | 延續 Zero to Growth 有機成長基因，沉穩有品味 |
| **深色反轉區（深墨橄欖）** | `#1B2419` | 用於「879 萬數據實績」與「爆款代表作」，製造視覺強弱節奏 |
| **活力點綴（焦糖琥珀橘）** | `#D46B34` | CTA 按鈕、重點標籤與互動強調色，帶出美食與探索溫度 |
| **暖金輔助色** | `#C59B56` | 深色反轉區塊的數字與細線點綴 |

### 字體與品牌識別
- **中文字體**：正式載入 `Noto Sans TC`（正文與 UI）＋ `Noto Serif TC`（編輯感大標題點綴），搭配 `Outfit`（數字與英數排版），徹底改善原本缺少中文字體而退回系統預設字的問題。
- **新版極簡 Logo**：以 SVG 重繪乾淨現代的幾何葉芽 Z 字徽章（取代舊版細碎藤蔓插畫 `logo.png`），在手機與桌面導覽列皆清晰銳利。

## 2. 強烈動態感與互動體驗藍圖（Motion Plan）

使用專案已安裝的 `framer-motion` 打造輕快、順滑、具「創作者生命力」的動態體驗（同時移除原本偏促銷感的 `.glow-gold` 呼吸發光陰影）：

1. **頂部細線閱讀進度條**：使用 `useScroll` + `useSpring`，隨滾動平滑推進。
2. **首屏 3 秒動態鉤子（Hero）**：
   - 大標題逐行遮罩滑出動畫（Mask Reveal）。
   - 右側改為**多層景深 9:16 互動貼文／Reel 輪播卡片**，自動輪播代表作並支援手動切換，搭配浮動即時戰績氣泡（`250,000+ 曝光`、`4,267 轉發`）與滾動輕盈視差。
   - 頂部導覽列加入錨點跳轉（數據實績、代表作、媒體陣容、合作方案）與快速問價按鈕。
3. **無限流動探索與戰績跑馬燈（Marquee）**：在首屏下方加入流暢橫向滾動條（懸停暫停），強化流量持續發酵的節奏感。
4. **滾動數字跳表（Count-Up）＋ 動態數據儀表板**：
   - 滑入視野時數字從 0 加速跳動至 `40,980+`、`879萬`、`+708%`。
   - 將原白底 Meta 後台截圖改為深色質感儀表板呈現＋「查看原始後台佐證」彈窗按鈕，避免白底截圖直接破壞版面，並避開原圖右上角易生誤解的 `US$0.00` 顯示區。
5. **性價比對決動態橫條對比**：以滾動展開的視覺長條直觀呈現「傳統 Meta 廣告（HK$80/千次曝光）」與「本矩陣推廣（HK$0.3 起/千次曝光）」的巨大成本差。
6. **代表作互動畫廊 + 詳情燈箱**：卡片交錯進場（Stagger Reveal），懸停微浮放大，點擊可展開詳細數據。
7. **報價方案「單月 ⇄ 季付 85 折」彈性切換開關**：點擊切換時，三檔套餐價格同步以動態動畫更新為折後月費並顯示節省金額。
8. **B2B 常見問題（FAQ）手風琴動畫**：補充商家最關心的合作流程、審稿與交付細節。
